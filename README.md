# Black November IngaCraft

Landing page da campanha Black November da IngaCraft, feita com React, TypeScript, Vite e Tailwind CSS.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Produção

```bash
npm run build
```

O resultado fica em `dist/`.

## Organização

- `src/pages/`: composição da página.
- `src/components/sections/`: seções da landing page.
- `src/components/layout/`: cabeçalho e rodapé.
- `src/components/ui/`: elementos reutilizáveis.
- `src/data/`: ofertas e perguntas frequentes.
- `src/lib/`: formatação e link de contato.
- `public/`: arquivos públicos da campanha.

O formulário abre o WhatsApp comercial com os dados preenchidos. O visitante precisa enviar a mensagem no aplicativo para concluir o contato.
